# Expense-Reconciliation-Engine

A Java-based collaborative expense tracking and settlement system with a desktop interface built using Swing. The application allows multiple users to record shared expenses and automatically calculates balances to determine who owes whom.

## Features
- Add and manage multiple users  
- Record shared expenses  
- Automatic balance calculation  
- Simple and interactive desktop UI using Java Swing  

## Tech Stack
- Java  
- Swing (GUI)  
- Object-Oriented Programming (OOP)  

## How to Run
1. Clone the repository  
2. Open the project in any Java IDE (IntelliJ / Eclipse / VS Code)  
3. Compile and run `FixedRateBillSplitter.java`  

## Future Enhancements
- Data persistence using files or database  
- Group-based expense tracking  
- Advanced split options (percentage, shares)  
- Export reports
